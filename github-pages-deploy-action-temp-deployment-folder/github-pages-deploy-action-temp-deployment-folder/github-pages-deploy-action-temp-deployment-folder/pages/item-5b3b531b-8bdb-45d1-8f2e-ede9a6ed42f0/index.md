How to Import an XLSX File as a Data Table and Build a Site in HAXcms
---------------------------------------------------------------------

Prerequisites
-------------

*   Ensure you have access to **HAXcms** and permission to edit pages.
*   Prepare your **XLSX file** with properly formatted data and clear headings.
*   Familiarize yourself with locating the **edit mode** (pencil icon) and the **Merlin/search bar** in HAXcms.

Want to follow along? Download the [example XLSX file (import-example.xlsx)](files/xlsx-data-table-and-site-import/import-example.xlsx) used in this tutorial.

Enter Edit Mode
---------------

Click the **pencil icon** to put your HAXcms page into edit mode. This enables you to make changes and import content.

Upload the XLSX File
--------------------

Drag and drop your **XLSX file** onto the **Merlin assistant** or the **search bar** at the top of the page. HAXcms will automatically detect the file type and present several import options.

Choose Import Option
--------------------

*   After dropping the file, you will see options such as:
*   **Insert as table** (recommended for data display)
*   Insert as CSV text
*   Link to the file
*   Upload only (no display)

For creating a data table, select **Insert as table**.

Review the Imported Table
-------------------------

HAXcms will instantly convert the XLSX file into a **highly accessible table** embedded in your page. The table will include headings and all content from your file. You can inspect the source to verify the table structure.

Inspect Table Structure
-----------------------

Right-click and select **View Source** to confirm that HAXcms has created a proper HTML table. You should see your headings and data accurately placed within table rows and columns.

Use XLSX Data to Build a New Site
---------------------------------

If your content is suitable, you can use the imported XLSX file to **create a new site hierarchy** in HAXcms. Go to the **Import** section and select **Excel** as the import type. This will allow HAXcms to generate a site structure based on your file's organization.

Verification
------------

*   Check that your table displays correctly with all data and headings intact.
*   Confirm that a new site hierarchy was created if you opted for site generation from Excel.
*   Test accessibility and layout to ensure your data is usable and well formatted in HAXcms.
