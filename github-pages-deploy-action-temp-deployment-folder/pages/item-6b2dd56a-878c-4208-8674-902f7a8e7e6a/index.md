How to Configure System Settings in HAXcms
------------------------------------------

Prerequisites
-------------

Before you begin, make sure you have **administrator access** to your HAXcms dashboard. Familiarity with basic navigation in HAXcms is helpful but not required.

*   Access to HAXcms site dashboard
*   Administrator privileges

Access the System Settings
--------------------------

From the site dashboard, click on your **user profile icon** in the top right corner. This opens a menu where you can toggle options like _dark mode_ and _sound effects_. To configure deeper settings, select **Settings** from this menu.

*   User profile icon location
*   Quick toggles: dark mode, sound effects
*   Navigation to settings panel

Review Status Information
-------------------------

Within the **Status** section, you can check the current version of HAXcms your site is running. Compare it with the latest available version. The status page also displays your server details and alerts you to any file system misconfigurations that require attention.

*   Current vs. latest HAXcms version
*   Server environment details
*   File system health and errors

Manage Skeletons
----------------

The **Skeletons** section lets you control which site creation templates (skeletons) are available. Check or uncheck skeletons to enable or disable them, then save your changes. This determines which templates users can select when creating new sites. You can also turn an existing site into a skeleton for future reuse.

*   Enable/disable skeletons for site creation
*   Save skeleton configuration
*   Convert a site into a reusable skeleton

Configure Themes
----------------

In the **Themes** section, you can enable or disable specific themes for your site. Disabling a theme removes it from user selection, helping to control the look and feel options available to site creators.

*   Enable/disable available themes
*   Streamline theme choices for users

Set Media Policies
------------------

The **Media** section allows you to define policies for image uploads. Set restrictions on image size, quality, and acceptable file formats to ensure media consistency and performance across your HAXcms sites.

*   Define maximum image size and quality
*   Specify allowed file formats

Explore Third-party Integrations
--------------------------------

The **Third-party Integrations** section is where you’ll eventually configure integrations with services like AI tools and YouTube. This area is still under development, so expect more options in future releases.

*   Upcoming integrations: AI, YouTube
*   Future expansion planned

Verification
------------

After updating system settings, refresh your dashboard to confirm your changes are active. Check that skeletons, themes, and media policies reflect your adjustments. If you encounter any errors, revisit the status section for troubleshooting tips.

*   Refresh dashboard to verify updates
*   Review enabled skeletons and themes
*   Consult status page for error messages
