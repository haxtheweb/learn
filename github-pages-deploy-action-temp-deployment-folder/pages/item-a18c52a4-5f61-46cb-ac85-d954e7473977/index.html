How to Edit a Page in HACS: Step-by-Step Tutorial

Prerequisites

  • Permissions: You need editing rights for the page you wish to modify.

Familiarity with basic navigation in HAX will help you follow these steps smoothly.

Open the Editor Panel

To begin editing, click the pencil icon at the top of the page. This action opens the editor panel, displaying the content blocks and page structure. You'll see the current source powering the page and a grayed-out section for settings.

Select and Edit Content Blocks

Click on any content block within the page body—such as a heading. The settings tab will open, allowing you to modify properties specific to that block. For example, selecting a heading reveals settings like text, lock status, and advanced developer options. Most users will focus on the Configure section for basic edits.

Edit Text and Block Type

  • Typing: Click into the text area and start typing or deleting as needed. The editing bar will disappear as you type and reappear when you pause.
  • Change Block Type: If you want to switch from a paragraph to another block type, use the tab provided in the editor panel.

This flexible editing lets you update content and structure easily.

Save Your Changes

Once you've made your edits, click the Save button to apply your changes to the page. This ensures all modifications are stored and visible to others with access.

Verification

Review the updated page to confirm your changes appear as intended. If necessary, repeat the steps to make further adjustments. Congratulations! You've successfully edited a page in HAX.
