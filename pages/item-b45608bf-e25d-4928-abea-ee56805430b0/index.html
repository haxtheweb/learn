Stuck? HAX is a community project and there are a few fast ways to get help. If you hit a bug or have a feature request, the issue queue is the canonical place to report it.

Get help

  • Post issues here: HAX issue queue on GitHub
  • Chat with the community on Discord

If you are already using HAX, clicking Merlin and typing "issues" can also shortcut you to submitting an issue report.

Common questions

Where is my content stored?

HAXcms stores pages as plain HTML files in pages/ and the site outline in site.json (JSON Outline Schema). Media lives in files/. Because it's all files, you can version, move, and host them anywhere.

Can I move a site to a different host?

Yes. A HAX site is portable. You can publish via Surge, Netlify, Vercel, GitHub Pages, or any static host, and the hax CLI can rsync a site to a remote directory.

How do I bring in content from Word or a spreadsheet?

Use the import paths in Import Content: DOCX and XLSX import are built in, plus HAX-to-HAX, Notion, ELMS:LN, and generic HTML import via the hax CLI.

Something looks broken — how do I report it?

File it in the issue queue with steps to reproduce. For quick questions, ask in Discord.
