Learn HAX is built from the HAX network, so the way to improve a tutorial is to improve the network, and the site follows.

Where the lessons come from
---------------------------

<editable-table scroll=""><table><thead><tr><th>Source</th><th>What it supplies</th></tr></thead><tbody><tr><td>Recorded tutorials</td><td>A video, its captions, a written walkthrough with screenshots, and the recorded steps, one folder per tutorial</td></tr><tr><td>PRAW ecosystem web</td><td>Maps of the system (importers, elements, flows, skills and more): what exists and how it connects</td></tr><tr><td>haxtheweb.org docs</td><td>The existing documentation, already mapped to web nodes</td></tr><tr><td>PRAW hax-imports</td><td>Sample files to follow along with: Word, PowerPoint, Excel, PDF, HTML, calendar and contact files</td></tr></tbody></table></editable-table>

How the site is updated
-----------------------

<ddd-steps-list><ddd-steps-list-item title="The network changes"><p>A capability, an element or a doc changes in a HAX repo and its node in the PRAW web is updated.</p></ddd-steps-list-item><ddd-steps-list-item title="A tutorial is recorded"><p>A two to three minute video and its transcript become a page with screenshots.</p></ddd-steps-list-item><ddd-steps-list-item title="Learn HAX rebuilds"><p>The page is added to the outline and published. Every time period shows the new lesson with no extra work.</p></ddd-steps-list-item><ddd-steps-list-item title="Gaps are suggested"><p>Web nodes with no tutorial, and tutorials that have gone stale, are listed as candidates.</p></ddd-steps-list-item></ddd-steps-list>
