Mastering Slash Commands for Efficient Content Editing
------------------------------------------------------

Prerequisites
-------------

*   **Access** to the content editor interface.
*   Basic familiarity with keyboard navigation.

Make sure you are logged in and have a document open for editing before starting.

Initiate Edit Mode
------------------

Begin by clicking the **Edit** button on your document. Then, click on any line where you want to insert content and press **Enter**. You should notice a faded message, such as _type slash for quick actions_, appearing on the new line.

Activate Slash Commands
-----------------------

Press the **slash ( / )** key on your keyboard. This action brings up a contextual menu, similar to the options bar at the top, but directly where you are editing. The menu will display available quick actions.

Insert Content Using Slash Commands
-----------------------------------

*   To add a video player, type **video** after the slash and press **Enter**. The video element is inserted instantly.
*   For headings, type **heading** and select the desired level (e.g., Heading 3).
*   To create a bulleted list, type **bulleted list** and press **Enter**.

Slash commands enable rapid content creation without needing to use the mouse.

Explore and Navigate Available Commands
---------------------------------------

You can scroll through the slash command menu to view all available options. This allows you to discover additional actions and formatting tools without leaving your current workflow.

Keyboard Efficiency and Alternative Access
------------------------------------------

All slash commands are also accessible from the top options bar. However, using the keyboard keeps your hands in place and speeds up editing, especially for long documents. Embrace slash commands to streamline your writing process and minimize interruptions.

Verification
------------

*   Check that the desired elements (video, heading, bulleted list) appear in your document after using slash commands.
*   Confirm that you can access all quick actions from both the slash menu and the top bar.
*   Practice using only keyboard shortcuts to maximize your editing speed.
