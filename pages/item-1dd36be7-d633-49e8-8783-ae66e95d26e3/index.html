Front-end developer

Luna has written JavaScript for over a decade. She's seen trends come and go in the many JS ecosystems and is burned out from constantly having to relearn "Thing + Ecosystem". HAX is appealing because it sits on web standards, is easy to piece through sites to trace relationships between HTML tags, and uses CSS variables. She also likes that she can make her own elements and themes using the CLI tools as well as publish using HAX11ty for higher SEO.

Where to start

These areas of Learn HAX map most directly to what Luna wants to do:

  • Developer Onboarding — fork and clone the repos, install, and verify each project runs.
  • Block Reference — the full inventory of HAX-capable elements and how they're used in the editor.
  • Release Notes — track what changes across HAXcms releases.

Looking to build new elements or themes? The Block Reference documents each component's usage; combine it with the HAX CLI to scaffold and publish your own.
