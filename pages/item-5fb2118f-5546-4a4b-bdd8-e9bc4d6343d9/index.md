How to Import a Website from a Word Document Using HAX
------------------------------------------------------

Prerequisites
-------------

*   **Word Document:** Have your _.docx_ file ready for import. This should be structured for web content.
*   **Example file:** Download the [import-example.docx](files/create-site-from-docx/import-example.docx) used in this tutorial and try the import yourself.

Start the Import Process
------------------------

Begin by clicking the **Import** option on the HAX dashboard. This opens up various import sources.

Select 'From Existing Source' and Choose Word Doc
-------------------------------------------------

Scroll down to find **From existing source**. Click on **Word doc** to specify that you want to import from a Word document.

Upload and Analyze Your Word Document
-------------------------------------

Upload your _.docx_ file. HAX will automatically analyze the document and confirm if it is structured for import. You should see a message indicating the file is compatible.

Name Your Site and Start the Import
-----------------------------------

Enter a name for your new site. Once named, click **Go** to begin the import process. You can either navigate directly to your new site or remain on the current page to watch the progress (including a confetti animation).

Access Your Imported Site
-------------------------

After import, scroll back up to the site list. Your newly imported site will be visible at the top. Click on it to open and review the imported content.

Review and Edit Imported Content
--------------------------------

Open the site to see the imported pages. You will notice that content from your Word document has been transferred. Pages may include placeholders for video or other media. You can add content, such as pasting a YouTube link, and the page remains fully editable.

Verification
------------

*   **Check imported content:** Ensure all text and media placeholders are present as expected.
*   **Editability:** Try editing a page (e.g., paste a YouTube link) to confirm the site is fully editable.
*   **Starting point:** Use the imported site as a base for further customization or as a distribution platform.
