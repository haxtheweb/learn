Learn HAX is where to learn HAX: tutorials, a reference for every block in the editor, and onboarding for people new to it.

It is made by the HAX project (HAXTheWeb), an open-source effort to let anyone author, remix and publish on the web without needing to learn how the web works. This site is itself a HAX site; [its source is on GitHub](https://github.com/haxtheweb/learn). Its content is shared under the Creative Commons Attribution-ShareAlike (CC BY-SA) license.

To see how every part of HAX connects, visit [hax.cloud](https://hax.cloud/). To get in touch, use the [Contact](contact) page.
