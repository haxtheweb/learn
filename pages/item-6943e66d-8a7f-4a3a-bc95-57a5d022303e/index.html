How to Create and Manage Pages in HAX

Prerequisites

Before you begin, make sure you have access to HAX and are logged into your account. Familiarity with basic navigation in HAX will help streamline the process.

  • Active HAX account
  • Basic understanding of the HAX interface

Locate and Use the Add Page Button

Find the blue Add Page button in the top corner of your HAX workspace. Click this button to start the process of creating a new page.

  • The Add Page button is easily visible and provides quick access to page creation features.

Create a New Page and Set Its Title

After clicking Add Page, a search bar appears. Here, you can type your desired page title. For example, entering Given Text will set this as your new page's title. Alternatively, pressing Enter without typing will create a page titled New Page.

  • Use the keyboard to navigate options such as duplicating the current page or creating a blank one.
  • Select Create Blank Page to start from scratch.

Understand and Edit the Page Slug and Title

The page slug (the URL segment after your site name) automatically matches your page title, e.g., Given-Text. Both the title and slug can be changed later if needed. To edit them, click Select to Edit Page Details in the page's content area. Here you can:

  • Change the page title
  • Edit the slug under Advanced
  • Adjust publishing status
  • Lock the page or move it in the outline
  • Save changes when finished

Add Content and Use Slash Commands

In the page editor, you can start adding content such as text, images, or videos. Use slash commands (e.g., /image) to quickly insert media and other elements. If you decide to change the page title while editing, simply access the page details as described above.

Save and Confirm Your New Page

After making your changes, click Save to update the page. The new title and slug will be reflected immediately, and your content will be preserved.

Add Pages Using the Outline Actions

Another way to add a page is through the Outline Actions menu. When working in the outline, click Add File Page to create a new page at your current location in the hierarchy. The process is similar to adding a page from the top menu, and you can press Enter to quickly create the page.

  • Pages added here can be organized as child pages under existing pages.

Organize Pages in the Hierarchy

Pages created via Outline Actions appear as child pages under the selected parent. This makes it easy to build structured content and maintain a clear hierarchy. You can move pages around as needed to reflect your desired organization.

Verification

To verify your new page, check the outline and the site URL to confirm the correct title and slug. Ensure your content appears as expected and that the page is in the intended location within the hierarchy.

  • Review the outline structure
  • Click the page to preview its content
  • Double-check the URL for accuracy
